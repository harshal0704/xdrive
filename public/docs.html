Everything you need to know about the Stealth Encoding Matrix and Zero-Knowledge Architecture deployed within XDrive.

> AES-256 ZERO KNOWLEDGE CRYPTOGRAPHY

XDrive uses Web Crypto API natively in your browser. When you input a secret key, the V8 engine immediately derives a cryptographic algorithm applying AES-GCM standards, adding a massive randomized Salt and Initialization Vector (IV).

THE EDGE SERVER NEVER SEES YOUR PASSWORD. IT NEVER SEES YOUR RAW DATA. If you lose your password, the payload is destroyed forever.

> PIXEL MATRIX INJECTION (STEGANOGRAPHY)

Once the browser encrypts your payload, it slices your encrypted blob into strict 2MB buffers to respect Vercel Edge constraints. These buffers are POSTed to the backend.

The backend reads the binary bytes, and systematically maps each byte iteratively into the Red, Green, and Blue channels of an uncompressed lossless PNG pixel grid!

> VERCEL SERVERLESS ARCHITECTURE

/api/encode

Stateless edge function. Receives 2MB binary arrays, wraps them in Jimp PNG structure, overrides Headers, and streams back `image/png` chunks.

/api/decode

Stateless edge function. Receives full PNG grid arrays, scans the RGB bounds for the 4-byte `XDRV` magic signature, extracts JSON headers + binary payload, and streams Base64 format string back to client.
