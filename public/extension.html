X_SCANNER

Chrome Extension

Automate the extraction of XDrive image payloads flawlessly from any X.com thread.

> INSTALL EXTENSION LOCALLY

DOWNLOAD REPOSITORY
  1. Open Google Chrome browser.
  2. Navigate to URL chrome://extensions/
  3. Toggle the Developer Mode switch ON in the top right.
  4. Click Load unpacked in the top left.
  5. Select the extension/ folder from your local XDrive repository.

How to Use:

Browse to an X.com post containing a thread of XDrive payload images. Click the neon yellow terminal icon in your extension bar and press "Extract Thread". It will aggressively scrape the network to fetch the lossless uncompressed matrices and automatically download the complete numbered sequence.
